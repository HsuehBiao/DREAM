# Dual High-order Random Walk Enhanced Adaptive Binary Multi-view Clustering

Official MATLAB implementation of our paper published in IEEE BIBM 2025.

# How to use

Run the 'copy_of_demo.m' on the built-in `prokaryotic.mat` dataset

# To run other datasets:
First adjust hyperparameters in 'parameter.m',
Then modify the dataset path in 'copy_of_demo.m' and re-run.
